⚡ A solución

Electroteca

Aplicación web SaaS para xestionar o inventario e as reparacións de equipos electrónicos.

Talleres Almacéns técnicos Departamentos TI Reparadores independentes

Multilingüe (galego · español · inglés) · accesible WCAG 2.1 · electroteca.jcrlabs.net dende calquera dispositivo

🛠️ Produto

Funcionalidades principais

Xestión de produtos

Nome, SKU, categoría e prezo. Inventario claro e accesible para os usuarios.

Estado de reparación

Cada equipo clasificado en reparado, en progreso ou non reparado para unha organización óptima.

Galerías, contactos e roles

Fotos do estado físico, contactos por equipo, categorías personalizables e roles (admin, xestor, visualizador).

⚙️ Stack

Tecnoloxías Backend e Datos

Go e PostgreSQL

Gin: latencias baixas, concorrencia nativa, binario estático. PostgreSQL: ACID, UUID e JSONB.

GORM e MinIO

GORM con migracións automáticas. MinIO: almacenamento de obxectos compatible con S3 para imaxes e arquivos.

Seguridade e escala

JWT, RBAC e bcrypt en cumprimento do RXPD. Orquestración en Kubernetes segura e escalable.

Go · Gin PostgreSQL MinIO
🎨 Stack

Tecnoloxías Frontend

React e TypeScript

Interface modular e robusta, con tipado estático que reduce erros en tempo de execución.

Vite

Bundler ultrarrápido con HMR instantáneo no desenvolvemento e builds optimizados para produción.

Tailwind CSS

Estilos utilitarios para un deseño consistente, responsivo e accesible (WCAG 2.1).

Zustand

Xestión de estado lixeira para a sesión, os tokens JWT e os datos da aplicación.

React TypeScript Vite Tailwind
🛠️ DevOps

Infraestrutura e Despregue

Docker

Contenedoriza frontend e backend en imaxes reproducibles, idénticas en local e en produción.

Kubernetes · k3s

k3s (Kubernetes lixeiro) orquestra con Helm: reinicio automático, RollingUpdate e escalado independente.

CI/CD · GitOps

GitHub Actions para integración (tests + imaxe) e ArgoCD para entrega continua baixo o patrón GitOps.

Nginx, Traefik e Cloudflare

Nginx serve o frontend e fai de proxy á API. Traefik como ingress e Cloudflare xestiona o DNS.

Docker Kubernetes GitHub Actions ArgoCD
☁️ Infraestrutura

Arquitectura e Despregue

Visión de alto nivel

SPA React + API REST Go en VPS Hetzner (datos na UE, RXPD) con k3s; backup de MinIO no VPS secundario.

Seguridade integral

JWT, RBAC, contrasinais con bcrypt e TLS automático con cert-manager.

Alta dispoñibilidade

Dúas réplicas de frontend e backend, con reinicio automático e RollingUpdate sen cortes de servizo.
